# wecom-bot-control-commands Delta Spec

## MODIFIED Requirements

### Requirement: 受限指令集

@FF 触发的交互会话 MUST 响应五个控制指令（逐字匹配，忽略 @FF 前缀与首尾空白）：`开始`、`暂停`、`状态`、`写入`、`放弃`。其他任何消息 MUST 进入意图分类处理（见 chat-driven-skill-config-editing 能力域）：可解析为变更请求的生成草案，可解析为只读查询的直接回答；两者都不改变系统状态。仅当消息无法解析时，MUST 回复固定帮助文案且不改变任何状态。

#### Scenario: 自由文本不改变状态

- **WHEN** 人在群内 @FF 发送「帮我加个监控 103300110003」但未完成确认闸（未回复「写入」，或草案已放弃/已被取代）
- **THEN** claw 不创建、不修改任何需求与 config（草案本身不改变系统状态）

#### Scenario: 自由文本进入草案解析

- **WHEN** 人在群内 @FF 发送「帮我加个监控 103300110003」
- **THEN** claw 不直接修改任何需求与 config，而是生成「待写入」草案并回复改前→改后对照与操作指引（「确认请回复：写入 / 放弃」）

#### Scenario: 无法解析的消息不改变状态

- **WHEN** 人在群内 @FF 发送无法解析为变更或查询意图的消息
- **THEN** claw 不创建、不修改任何需求、草案与 config，回复固定帮助文案

#### Scenario: 群里无鉴权前提

- **WHEN** 目标群内只有 FF 机器人与李非凡两个成员
- **THEN** 交互会话对 @FF 消息不做身份鉴权；若群成员构成变化，须重新评估此前提
